# 🎬 Movie Ratings Analysis
**Tools:** SQL Server · Power BI · Power Query

## 📌 Project Overview
Analyzed 1,726 IMDb movies to uncover trends in 
ratings, genres, directors, and audience behavior.

## ❓ Business Questions Answered
1. What are the top 10 highest rated movies?
2. Which genre has the highest average rating?
3. Which director has the best average rating?
4. Which PG rating gets the best audience scores?
...and more!
## 🛠️ What I Did
- Cleaned raw data in SQL Server (removed NAs, 
  fixed data types, parsed duration to minutes)
- Wrote 11 SQL queries to answer business questions
- Built interactive Power BI dashboard with:
  - 4 KPI cards
  - 5 charts (bar, line, donut)
  - Genre & Year slicers
  - Drill-down director tooltips

## 📊 Key Findings
- Western is the highest rated genre (avg 7.80)
- Movie production grew sharply after 2000
- Frank Capra is the highest rated director (3+ movies)
- R-rated movies get the highest audience ratings
